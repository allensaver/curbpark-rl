# v2c 设计：平衡调参轮（2026-10-28 定案）

## 背景与决定

第 2 周结论：v2b 三种子合计成功 3/150 = 2%、碰撞 4%、平均位置误差 15.1m，
主导失败为超时打转 134/150（89%）；300k 续训诊断已否证「只是训练不够」
（成功 6%→0%、碰撞 8%→28%），瓶颈定位在奖励配比与 PPO 不稳定性。
2026-10-28 Zequan 拍板：先进第 3 周鲁棒性评测之前，先做一轮 v2c 平衡调参。

本轮性质与第 2 周不同：第 2 周是单因子消融（归因），本轮是调参
（在已归因的三个假设上同时动配比，目标是拿到站得住的成功率）。
因此本轮结果只回答「配比调了之后整体变好还是变坏」，不做单项归因。

## 改动（相对 v2b，其余全部不变）

| 旋钮 | v2b | v2c | 对应的诊断假设 |
|---|---|---|---|
| 碰撞代价 | −50 | **−30** | (b) −50 使价值函数对靠近已停车辆过度恐惧，而目标车位恰在已停车辆之间；−30 是 −5 与 −50 的中间带 |
| 进度塑形权重 | 0.15/米 | **0.30/米** | (c) 远处进度信号偏弱，不足以驱动果断接近 |
| 末端精调权重 | 0.03/步 | **0.06/步** | 区域内摆正信号弱，斜停/末端对位不足 |
| 终局成功奖励 | +15 | **+30** | 完成激励相对碰撞代价偏弱，策略宁可超时也不冒最后一段险 |

不变项：区域一次性奖励 +4（≤3m 且航向 ≤30°）/ +8（成功层）、进度截断 ±0.5、
PPO 超参、训练步数 150k、评测口径（固定 50 场景种子 1000–1049、
成功 = 位置 ≤1.5m 且航向 ≤15°、评测回报按 v1 口径）。

套利复核（防撞停投机回潮）：以第 1 周实测计，快速撞停约 15 步、
基础距离惩罚累计 ≈ −7，v2c 下撞停总回报 ≈ −37；超时失败在 v2b 实测
回报为 −40～−46，但那是未含进度/区域奖励的 v1 评测口径——训练口径下
认真接近可累计进度塑形与区域奖励，期望回报高于撞停。是否回潮不靠推算、
靠护栏指标实测（见下）。

## 执行计划（沿用第 2 周两阶段打法）

- **阶段一（筛选）**：种子 0 训练 150k 步 → 同一评测集评测。
  命令：
  `.venv/bin/python src/train_ppo.py --seed 0 --timesteps 150000 --reward-version v2c --out models/ppo_v2c_seed0`
  `.venv/bin/python src/evaluate.py --model models/ppo_v2c_seed0 --episodes 50 --out results/v2c/eval_v2c_seed0`
- **晋级门槛（种子 0 与 v2b 种子 0 对比：成功 6%、碰撞 8%、误差 10.0m）**：
  - 成功率 > 6%，且碰撞率 ≤ 20%（护栏：超过说明降碰撞代价过头、套利回潮），
    且平均位置误差不劣于 10.0m → 进阶段二，补种子 1、2 做多种子结论；
  - 成功率没动或碰撞明显回潮 → 不补种子，如实记录 v2c 失败，
    回到「接受 v2b@150k 种子 0 为第 3 周对象」的备选路线再议。
- **阶段二（视阶段一结果）**：种子 1、2 同配置训练+评测，给出三种子合计表
  与失败分型，写入 `results/v2c/第3周前调参结果说明.md`（文件名定稿时再定）。

## 风险与诚实标注

- 同时动四个旋钮意味着即使变好，也不能说清是哪一项的功劳——这是调参轮
  的已知代价，讲述时要明说，不要包装成消融结论。
- PPO 不稳定性仍在：单种子筛选只作晋级判断，任何成功率结论必须等
  三种子合计后才成立（第 2 周种子 0 的 6% 就是前车之鉴）。
