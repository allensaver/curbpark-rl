# 第 3 周鲁棒性评测结果说明（2026-10-28 实测）

评测口径与第 2 周一致：固定 50 场景（种子 1000–1049）、确定性策略、
成功 = 终态位置误差 ≤1.5m 且航向误差 ≤15°、指标一律按真实状态计算。
对象：v2b@150k 种子 0。扰动只加在策略“看到”的自车位置上（观测与
achieved_goal 同步加扰，desired_goal 来自地图不加扰），物理对应为定位误差。
设计与预设判据见 `鲁棒性评测设计.md`；原始数据见 `robust_*.csv` 与
`robust_summary_all.json`。本轮 7 个条件全部跑完，不挑单条件写结论。

## 干净基准（第 2 周同口径实测，复用不重跑）

| 指标 | 数值 |
|---|---|
| 成功率 | 6%（3/50） |
| 碰撞率 | 8%（4/50） |
| 平均位置误差 | 10.0m |
| 失败分型 | 超时打转 38、碰撞 4、斜停 3、越位 2 |

## 全部 7 个条件结果

| 条件 | 成功 | 碰撞 | 平均位置误差 | 失败分型（超时 / 碰撞 / 斜停 / 越位 / 成功） |
|---|---|---|---|---|
| 干净基准 | 6%（3） | 8%（4） | 10.0m | 38 / 4 / 3 / 2 / 3 |
| 高斯 σ=0.5m | 6%（3） | 8%（4） | 10.01m | 38 / 4 / 4 / 1 / 3 |
| 高斯 σ=1.0m | 4%（2） | 12%（6） | 10.13m | 38 / 6 / 3 / 1 / 2 |
| 高斯 σ=2.0m | 4%（2） | 8%（4） | 9.75m | 36 / 4 / 7 / 1 / 2 |
| 固定偏置 +1m | 0%（0） | 16%（8） | 10.26m | 38 / 8 / 4 / 0 / 0 |
| 固定偏置 +2m | 0%（0） | 16%（8） | 10.67m | 41 / 8 / 1 / 0 / 0 |
| 高斯 σ=1.0m + 5 步平滑 | 4%（2） | 6%（3） | 10.06m | 37 / 3 / 8 / 0 / 2 |
| 高斯 σ=2.0m + 5 步平滑 | 2%（1） | 6%（3） | 9.58m | 34 / 3 / 10 / 2 / 1 |

注：每 1 个回合 = 2 个百分点，50 场样本下 1–2 回合的波动都在噪声量级，
下文只把“成功归零”“碰撞翻倍”这类跨条件一致的形态当作结论，
单条件 1 回合的差异不单独立论。

## 结论 1：随机噪声的退化曲线是平的——不是因为策略强，而是因为它本来就没停好

高斯噪声从 0 加到 2.0m，成功率只从 6% 滑到 4%，平均位置误差一直在
10m 上下（10.01 / 10.13 / 9.75m），碰撞率 8%→12%→8% 也没有单调爬升。
设计时预期的“碰撞对位置噪声最敏感”没有明显兑现。

解释是地板效应：干净状态下已有 38/50（76%）是超时打转，策略大多根本
走不到需要精确定位的终局；观测抖动改变不了一个“到不了终局”的策略的
结局分布。所以这条平曲线不能读成“策略对噪声鲁棒”——它读成
“噪声不是当前瓶颈，完不成停靠才是”。面试讲述时必须带上这句限定，
否则就是把弱点包装成优点。

## 结论 2：系统性偏置是真正的断点——1m 偏置就足以清零成功、碰撞翻倍

两个偏置条件成功率均为 0%（干净 3 个成功全灭），碰撞率均为 16%
（干净 8% 的两倍），平均位置误差也随偏置增大而变差（10.26m、10.67m）。
随机抖动可以被策略的保守性“平均掉”，恒定偏置不能：它让策略全程
对着一个错位的目标点做决策。

方向性迹象（次要观察，样本小、只作方向验证）：在非超时回合
（即真正走到目标附近的子集）中，纵向误差均值从干净的 +0.71m
（n=12）变为偏置 +1m 组的 +2.32m（n=12）、+2m 组的 +3.34m（n=9），
随偏置单调增大，与 +x 偏置方向一致；高斯组该值在 +0.44~+1.51m 之间。
但子集小且混有碰撞/斜停回合，只能算方向性迹象，不能当作精确标定结论。
全量平均纵向误差（约 −9m）则被超时回合主导，不能用来验证偏置方向。

产品化含义：对泊车这类终局精度任务，定位标定误差（系统性）比
传感器抖动（随机性）更值得优先投入——这正是“标定与在线校准”
在量产泊车里的权重来源。

## 结论 3：5 步平滑防御按预设判据算“有效”，但收益小且有可预见的代价

预设判据：同 σ 下碰撞率与位置误差同时改善才算有效。

- σ=1.0m：碰撞 12%→6%、位置误差 10.13m→10.06m，两项都改善，判有效；
  成功率不变（2→2）。
- σ=2.0m：碰撞 8%→6%、位置误差 9.75m→9.58m，两项都改善，判有效；
  但成功率 2→1（少 1 回合，噪声量级内），不能宣称“防御提升了成功率”。

代价与设计时的预告一致：平滑引入滞后，斜停回合明显增多——
σ=1.0m 组 3→8、σ=2.0m 组 7→10。也就是说滤波帮策略“少撞”，
却让它在末端精调时更容易停歪。这是 5 步滑动平均这种最简滤波的
固有取舍，不是实现 bug；若要更好，需要带速度/航向的状态估计
（如卡尔曼滤波）而不是更长的滑动窗口。

## 与学姐工作的诚实边界

本轮与学姐无人机项目的方法同构（强度扫描出退化曲线 + 防御前后对比），
但威胁模型不同：她是 PGD 对抗扰动（最坏情况），本轮是随机噪声与
系统偏置（平均情况）。讲述时必须明说这一区别，不冒充对抗攻击评测。
相应的，结论也只能落在“平均情况定位误差”上，不能外推到“抗攻击”。
