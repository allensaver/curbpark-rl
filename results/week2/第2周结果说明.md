# 第 2 周结果说明：奖励改造消融（2026-10-26 实测）

评测口径与第 1 周完全一致：固定 50 个场景（种子 1000–1049）、确定性策略、
成功 = 终态位置误差 ≤1.5m 且航向误差 ≤15°。所有版本均用 PPO 训练 150,000 步。
注意：评测回报统一按 v1 环境口径计算，跨版本可比。

## 结论（分清“稳健成立”与“不成立”）

**稳健成立的两个效果（3 个种子方向一致）：**
1. **撞停投机被消除**：碰撞率 100% → 4%（v2b 合计）。只改碰撞代价的 v2a 也得到 2%，
   证明这一步的因果来自代价项本身，而非区域奖励。
2. **接近目标的能力真实提升**：平均位置误差 25.7m → 15.1m。策略从“开出去撞死”
   变成“能开向目标区域附近”，进度塑形与区域奖励的方向是对的。

**不成立/需要诚实标注的：**
3. **成功率并不稳健**：6% 只出现在种子 0，种子 1、2 均为 0%，合计仅 2%。
   单种子结果不能写进简历当结论——这正是做多种子的意义。
4. **主导失败已转移为超时打转（89%）**：策略变得过度谨慎——在 100 步内完不成
   最后的对位与摆正。合理解释有三（待诊断区分）：
   a) 150k 步对末端精细机动不足；
   b) 碰撞代价 −50 让价值函数对“靠近已停车辆”过度恐惧，而目标车位恰恰在已停车辆之间；
   c) 进度塑形权重（0.15/米）相对偏弱，远处信号不足以驱动果断接近。

## 诊断实验（已完成）：续训 +150k 步（总 300k）

v2b 种子 0 在 150k 基础上续训 150k 步后复测：

| 指标 | 150k | 300k（续训） | 变化 |
|---|---|---|---|
| 成功率 | 6% | **0%** | 3 个成功回合全部消失 |
| 碰撞率 | 8% | **28%** | 明显变差（碰撞 4 → 14） |
| 平均位置误差 | 10.0m | 9.4m | 略有改善 |
| 失败构成 | 超时 38、碰撞 4 | 超时 34、碰撞 14、斜停 2 | — |

**诊断结论：否证“只是训练不够”这一简单解释。** 更多训练没有解决超时，反而让策略
沿着“接近能力 vs 安全”的前沿滑动：开得更近了（位置误差略降），但撞得更多、
原有的成功回合也丢了。这同时暴露了 PPO 在该任务上的训练不稳定性（同配置续训
即可让成功率从 6% 归零）。因此瓶颈更可能在奖励平衡本身：
碰撞代价 −50 与完成激励之间的配比、以及末端机动的信号强度，
而不是原始训练步数。第 3 周（鲁棒性评测）开始前，建议先做一轮小规模 v2c 平衡
调参（如碰撞代价中间值 + 强化终局/精调激励），或明确接受以 v2b@150k 种子 0
作为鲁棒性评测对象并把其脆弱性本身写进分析。

## 对面试讲述的意义

这一周的完整故事是：基线投机（第 1 周）→ 单因子堵漏 → 新失败模式出现（超时）→
区域奖励改善接近能力 → 多种子证伪单点成功率 → 用续训诊断区分原因。
“改了什么、哪个指标动了、有没有把别的指标弄坏”每一环都有数据，
这就是 Failure Case 驱动的奖励迭代，也是学姐简历中 Reward 建模工作的同构缩小版。
